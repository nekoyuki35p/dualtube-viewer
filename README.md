# DualTube Viewer Web v0.5.0

## 主な追加・変更
- 50:50 / 70:30 / 30:70 の表示比率
- 「動画入替」と「メイン交換」を分離
- 各プレイヤーの個別全画面ボタン
- 動画再生中のみ Screen Wake Lock で画面消灯防止
- 縦画面では「上 / 下」、横画面では「左 / 右」へUIを自動変更
- 端末方向は保存しない
- 共有時、空き枠があれば確認なしで自動投入
- 両枠が埋まっているときだけ入替先を選択
- サイレント自動更新。視聴中の強制リロードなし
- v0.4.5の履歴 / お気に入り / バックアップ / エラー案内を維持
- v0.4.5バックアップとの互換性を維持

## 70:30表示について
横画面は左右の幅を7:3で割り当てます。
縦画面はYouTubeプレイヤーを極端に低く潰さないため、16:9を維持しながらサブ画面を縮小します。
サブ画面は操作性確保のため最小200 CSS pxです。

## 実機で確認したい項目
- 50:50 / 70:30 / 30:70
- メイン交換で再生位置が維持される
- 動画入替で再生位置が維持される
- 上/下それぞれの全画面と復帰
- 横回転時に上/下表記が左/右へ変わる
- Wake Lock ONで再生中に画面が消灯しない
- 共有時の空き枠自動投入
- 両枠使用時だけ共有先選択が出る
- 履歴 / お気に入り / バックアップ
- 次回起動で新版が反映される
