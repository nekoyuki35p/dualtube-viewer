# DualTube Viewer Web v0.5.4

## デザイン調整版 A
機能とレイアウトは v0.5.3 のまま、配色だけを変更しました。

### 新しい配色
- 背景: ダークネイビー
- パネル: ネイビー / スレート
- メインアクセント: シアン
- 文字: 白〜ブルーグレー
- お気に入り: 黄色
- エラー / 削除: 赤

黒＋ネオンピンク中心の印象をやめ、動画ツールらしい落ち着いた配色にしています。
夜間の見やすさは維持しつつ、一般的なアプリ寄りの雰囲気を狙っています。

## 変更していないもの
- UIレイアウト
- ボタン配置
- 視聴モード
- 50:50 / 70:30 / 30:70
- 個別全画面
- 画面消灯防止
- 縦 / 横UI切替
- 履歴 / お気に入り
- 共有機能
- バックアップ / 復元
- アイコン
