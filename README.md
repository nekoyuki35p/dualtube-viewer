# DualTube Viewer Web v0.5.1

## 修正内容
v0.5.0で `swapBtn` のDOM参照が `els` に登録されていなかったため、
JavaScriptの初期化が途中で停止していました。

その影響で、初期化処理の後半にある以下のボタンが反応しない状態でした。
- 視聴モード
- 横画面 / 縦画面
- 設定

v0.5.1では `swapBtn` の参照を追加し、初期化処理が最後まで完了するよう修正しています。

## 維持される機能
- 50:50 / 70:30 / 30:70
- 動画入替
- メイン交換
- 上下それぞれ個別全画面
- 画面消灯防止
- 縦画面の上 / 下、横画面の左 / 右UI
- 共有時の空き枠自動投入
- 履歴 / お気に入り
- バックアップ / 復元
- サイレント自動更新

## GitHub Pages更新
ZIP内をそのまま上書きしてください。

- index.html
- sw.js
